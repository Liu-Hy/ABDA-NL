Statements & glossary

                
Write each statement in plain English. Facts are given, assumptions are defeasible, and claims follow from rules. Mark the claims you want to feature as key conclusions.

                

                
                
Rules

                
Select what must hold and what follows. Usually allows competing arguments. Always makes a strict rule.

                

                
              

              

                

                  

                
Use -> for strict rules, => for defeasible rules, and -p for negation. In native ABDA files, blank lines separate defeasible preference blocks, with later blocks stronger. Explicit # Block N markers override blank-line grouping. Keep identifiers to preserve their meanings.

                
Switch back to Guided to edit meanings and choose key conclusions. Invalid text never replaces the last valid draft.
